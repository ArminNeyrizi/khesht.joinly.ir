# Khesht Academy

Next.js + TypeScript + Tailwind CSS + shadcn-style UI starter for Khesht Academy.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Pages

- `/` Home
- `/courses` Courses
- `/course` Course detail
- `/blog` Blog
- `/about` About
- `/contact` Contact

Replace the demo Unsplash images and connect the contact form to your backend/API.
